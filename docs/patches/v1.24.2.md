# v1.24.2

## Purpose

Fix two regressions found after v1.24.1 automatic measurement.

## Changes

1. Restore automatic ZIP download at measurement completion.
   - The visible "計測ZIPを保存" link is still shown as a fallback.
   - A programmatic download is attempted after ZIP creation.

2. Change the ZIP internal directory structure.
   - Before: CSV files were stored at the ZIP root, so extraction used the ZIP filename as the folder name on some environments.
   - After: all generated files are stored under `runN/`, where `N` is the entered run number.
   - Example: run 5 extracts to `run5/metadata.csv`, `run5/summary.csv`, `run5/validation.csv`, `run5/01.csv` ... `run5/37.csv`.

No physics, measurement metrics, game logic, or geometry processing was changed.
