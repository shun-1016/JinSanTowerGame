# v1.27.0

## Purpose
v1.27.0 keeps the v1.25.1 physics/measurement behavior and adds contact-geometry diagnostics.

## Physics
No physics parameters are changed.
The 4-substep configuration from v1.25.x remains the baseline.

## Added detailed CSV columns
- contact_min_y / contact_max_y / contact_mean_y
- contact_left_offset_px
- contact_right_offset_px
- contact_span_from_com_px
- contact_normal_angle_rad
- contact_torque_proxy
- contact_com_distance_px
- contact_asymmetry_px

These are intended to distinguish:
- contact position relative to the COM
- contact asymmetry
- contact normal direction
- a normalized geometric torque proxy

`contact_torque_proxy` is a geometry/direction proxy, not an actual collision impulse or physical torque.

## CSV size strategy
- Detailed data remains one CSV per piece.
- Summary files remain split into chunks of at most 10 pieces.
- The number of pieces is discovered dynamically; no 37-piece hard-code is introduced.
- No extra per-frame rows are generated.
- Existing ZIP/run structure and validation are preserved.

## Application
Apply `js/measurement.js.patch` to the v1.25.1 `js/measurement.js`.
Do not apply this patch to v1.26.0.
