# v1.24.1

## 目的

v1.24.0の自動計測処理を、通常ゲームの物理更新と二重実行しない構成へ整理する。

## 構成

- `js/game.js`
  - ゲーム本体のみを担当。
  - v23.5時代の計測処理を完全に削除。
- `js/measurement.js`
  - 自動計測を一元管理。
  - `Game.update()` の後段で状態を観測する。
  - 計測側から `Physics.step()` は呼ばない。
  - 通常の `Game.render()` に計測対象を描画する。
  - 完了時にZIPを自動生成し、モード選択画面を復帰させる。
- `js/physics-stabilization.js`
  - 着地時の対象限定補正。
  - 同時に着地前後の衝突診断値を `v238Diagnostics` として計測側へ提供。
- `index.html`
  - バージョン付き旧ラッパーを読み込まず、現行JSだけを読み込む。

## 重要な修正

v1.24.0では計測処理自身が `Physics.step()` を呼んでいたため、通常のゲームループと合わせて1フレームに2回物理計算されていた。v1.24.1ではこれを廃止し、通常ループの1回だけを使用する。
