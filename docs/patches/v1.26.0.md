# v1.26.0

## Purpose
A/B experiment using 8 physics sub-steps per frame.

## Changes
Only `js/physics.js` is changed:

- Version comment: v1.25.0 -> v1.26.0
- `SUB_STEPS`: 4 -> 8

The total simulated time per frame is unchanged:
`subDt = totalMs / SUB_STEPS`, followed by `SUB_STEPS` calls to `Engine.update()`.

## Explicitly unchanged
- Alpha-derived collision geometry
- Transparent holes / concavities / narrow protrusions
- Convex decomposition logic
- Mass / density / inertia
- Friction / restitution / air friction
- Gravity
- Solver iteration counts
- Existing stabilization logic
- Measurement system
- Dynamic piece-count handling

This is intended to isolate the effect of increasing temporal resolution from 4 to 8 sub-steps.
