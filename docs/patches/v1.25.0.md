# v1.25.0

## 目的
v1.24.2を基準として、物理演算の時間刻みだけを4分割する純粋なサブステップ実験版。

## 変更点
- `js/physics.js` の `Physics.step(dt)` 内だけを変更。
- 従来の1ステップを4等分し、`Engine.update(engine, dt / 4)` を4回実行。
- αマスクから生成する物理形状は変更しない。
- `positionIterations: 12`
- `velocityIterations: 8`
- `constraintIterations: 2`
- friction / frictionStatic / frictionAir / restitution / density / slop / gravity は変更しない。
- 既存の着地安定化処理も変更しない。
- `measurement.js`、`game.js`、`piece.js`、`renderer.js`、`input.js`、`main.js` のロジックは変更しない。

## 検証目的
v1.24.2との比較で、
- 着地時のΔvx / Δvy / ΔangularVelocity
- 着地後のX移動量
- 着地後の角度変化
- バウンス高さ
- sleepまでの時間
を確認する。

この版では他の安定化策を同時に入れない。4 sub-step単独の効果を切り分けるための実験版。
