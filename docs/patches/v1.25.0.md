# v1.25.0 — 4 sub-step pure experiment

## Purpose
Test whether Matter.js 0.20.0 collision/stacking behavior improves when one
60 Hz physics step is internally divided into 4 equal sub-steps.

## Experimental control
This version changes only the time integration granularity in `js/physics.js`:

- `Engine.update(engine, dt)` → 4 × `Engine.update(engine, dt / 4)`
- `SUB_STEPS = 4`

The following are intentionally unchanged:

- alpha-derived exact physics geometry
- transparent holes / concavities
- mass, density, inertia
- friction / frictionStatic / frictionAir
- restitution
- gravity
- position/velocity/constraint iterations
- collision diagnostics
- existing targeted landing correction in `js/physics-stabilization.js`
- measurement CSV structure and run-folder structure

## Important
`js/measurement.js` is the proven v1.24.2 measurement implementation with
only its displayed version changed to v1.25.0. This avoids the previous
v1.25.0/v1.24.2 debug UI version conflict without changing measurement logic.

The landing correction remains in `js/physics-stabilization.js` because this
is an A/B experiment against the working v1.24.2 baseline: the only new
physics variable must be the 4 sub-steps.

## Expected test
1. Apply the files to `develop`.
2. Open `?debug=on`.
3. Run exactly 1 automatic measurement.
4. Confirm all 37 pieces complete and the ZIP is generated.
5. If valid, run 5 trials total.
6. Compare against v1.24.2, especially:
   - `landing_delta_vx`
   - `landing_delta_vy`
   - `landing_delta_angular_velocity`
   - `max_post_land_abs_vx`
   - `max_post_land_abs_angular_velocity`
   - `post_land_x_range`
   - `post_land_angle_range`
   - `max_bounce_height_px`

No alpha-shape simplification is introduced.
