# v1.24.0 構成変更

## バージョン管理
今後は Semantic Versioning 形式の `vMAJOR.MINOR.PATCH` を使用する。

- 現行: `v1.24.0`
- MAJOR: 大規模な仕様・互換性変更
- MINOR: 機能追加・大きな改善
- PATCH: バグ修正・小規模修正

これまでの `v23.x` は履歴として保持し、過去ログのパスは変更しない。

## JavaScript構成
バージョン番号付きの差分・ラッパーJSを廃止し、通常のファイル名を使用する。

- `js/physics.js`
- `js/physics-stabilization.js`
- `js/piece.js`
- `js/renderer.js`
- `js/input.js`
- `js/game.js`
- `js/main.js`
- `js/measurement.js`

`physics-stabilization.js` は着地時の補正を担当する独立した完成モジュール、`measurement.js` は計測UI・計測処理・描画・ZIP出力を一体管理する。
