# JinSan Tower Game

## v23.3
v23.3はv23.1をベースに、**物理パラメータを変更せず**、着地安定性の原因を切り分けるための接触形状計測を追加したバージョンです。通常ゲームの物理挙動・ピース形状生成は変更していません。

### v23.1 デバッグ計測
`?debug=on` でゲームモード選択画面に「全37ピース自動計測」が表示されます。

- 01〜37を順番に単独落下
- 全ピースを同じ初期位置・初期角度・初速0で計測
- 落下開始から接地を検出
- 接地後60フレームまで継続記録
- 位置、速度、角速度、角度、Sleep状態、接地状態をフレーム単位で記録
- 質量、慣性、重心ズレ、従来の底面幅、縦横比、物理パーツ数、三角形数、領域数、輪郭頂点数も記録
- 最下端から1/2/4/8px以内の物理頂点幅を記録
- 実際の地面接触点の幅、接触点数、接触パーツ数、接触中心のズレを記録
- 計測完了後、CSVを自動出力し、画面から再保存も可能

### CSV
ファイル名は `JinSanTowerGame_v23.3_physics_log_YYYYMMDDHHMMSS.csv` です。
CSVはUTF-8 BOM付きで、Excel等で開いた際に日本語が文字化けしにくい形式です。

### 通常ゲーム
v23.1では通常ゲームの物理パラメータ、ピース形状生成、ゲームルールを変更していません。


## v23.3 修正内容
- v23.0で発生していたデバッグモード起動時のJavaScript初期化順序エラーを修正。
- デバッグ用計測UIを通常モードでは明示的に非表示にする処理を追加。
- 着地時の接触形状を詳しく計測できるようCSV項目を追加。
- 通常モード、エンドレスモード、自動計測が起動できる状態に修正。
- v23.3では物理パラメータとピース形状生成を変更していません。

- v23.3: 実際の接触点取得を Matter.js 0.20.0 の pair.contacts / contactCount に修正。物理挙動・形状生成・その他の計測項目は変更なし。
