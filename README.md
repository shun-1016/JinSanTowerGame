# JinSan Tower Game v18.2

v18.2: PNGのアルファ輪郭を起動時に自動解析し、Matter.jsのcompound bodyへ変換する版。

## 今回の修正
- v18.1で発生した物理形状の部分欠落によるパーツ同士・土台へのめり込みを修正。
- 輪郭の三角形分割が完全成功しない場合は部分形状を採用せず、矩形フォールバックを使用。
- 外側の最大輪郭のみを物理形状として採用し、内部輪郭を誤って塗りつぶす問題を回避。
- Matter.jsの内部エッジを内部衝突として扱わないよう設定。
- 画像中心と物理ボディの重心差を補正し、表示画像と物理形状を整合。
- 輪郭デバッグを常時表示。赤線・赤点が自動解析した輪郭。画面左上に解析頂点数と三角形数を表示。
- style.cssをZIPに明示的に含め、今回のCSS変更も確実に引き継ぐ。

## 維持
ソロプレイ、カメラ制御、スタンバイ位置、横フリック、タップ時の位置ジャンプ防止、500ms次ピース待機、回転操作、スマートフォンUI。
