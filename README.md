# 仁さんタワー

## v22.5

v22.5 は、v22.0 で導入した「穴をブリッジして1つの多角形へ変換する方式」を廃止し、**B案：透明部分を物理的に埋めない複数領域方式**へ変更したバージョンです。

### 今回の変更

- 画像のアルファ値から不透明領域を直接抽出
- 水平方向の不透明ランを縦方向に結合し、複数の矩形領域として物理形状を生成
- 隣接する同一帯の矩形も結合してMatter.jsの物理パーツ数を抑制
- 透明部分・画像内の穴を物理形状として埋めない
- v22.0 の `NO_EAR_FOUND` → 正方形Fallbackにつながる穴ブリッジ処理を廃止
- v21.8.4系の輪郭簡略化（`ALPHA_THRESHOLD=96`、段階的RDP）は維持
- `.png` / `.PNG` の大文字小文字混在に対応
- 37種類のピースを対象
- `physics.js` の重力・摩擦・反発・反復回数など、v20.5を基準とした安定性設定は維持
- デバッグ表示に「領域」数を追加

### 物理形状の考え方

v22.0では、

`画像 → 外周＋穴 → 穴をブリッジ → 1つの多角形 → 三角形化`

という流れでした。

v22.5では、

`画像のアルファ → 不透明領域を直接分割 → 複数の物理領域 → Matter.jsの剛体`

としています。

この方式では、透明部分を「穴のある1枚の多角形」として扱わないため、穴ブリッジによる自己交差や `NO_EAR_FOUND` を避けられます。

### デバッグモード

URL末尾に `?debug=on` を付けると物理形状の確認ができます。

例:

`?debug=on`

特定ピースを確認する場合:

`?debug=on&piece=24`

赤線が実際のMatter.js物理形状、青線が画像から抽出した輪郭です。

表示項目:

- 輪郭頂点
- 簡略化後の頂点数
- 面積
- 自己交差
- 三角形化結果
- 物理凸ポリゴン数
- 物理頂点数
- 不透明領域数
- 穴数
- Fallbackの有無

### JavaScriptの役割分担

- `js/physics.js`：Matter.js、重力、衝突、物理形状生成
- `js/piece.js`：画像読み込み、アルファ解析、輪郭・不透明領域生成
- `js/renderer.js`：Canvas描画、デバッグ表示、エフェクト
- `js/input.js`：タッチ・ボタン入力
- `js/game.js`：ゲーム状態、モード、スコア、ピース選択
- `js/main.js`：起動・ゲームループ

### アセット

## v22.5 物理挙動調整
- v22.5のB案による物理形状生成は変更していません。
- 着地直後の過大な角速度を上限設定＋軽い角速度減衰で抑制。
- 落下開始から一定時間はさらに低い角速度上限を適用。
- 積み上がったピースが微小な衝突補正で長時間震え続ける現象を、低速時の早期スリープで抑制。
- Matter.jsの基本的な重力・反復回数・形状生成アルゴリズムは維持。
- デバッグ時に速度・角速度・SLEEP/AWAKE状態を表示。


### v22.5
- 物理形状生成はv22.1/v22.2系を維持。
- 着地時の線形速度・角速度を強く減衰し、多重バウンドと急回転を抑制。
- 接触後に低速になった積み上げピースを早期Sleep。
- 摩擦・空気抵抗・slopを安定化方向へ調整。
- 画像輪郭・透明領域の解析アルゴリズムは変更していない。


## v22.5 物理挙動・ゲームオーバー修正
- v22.1/v22.2系の透明領域を埋めない物理形状生成は変更していません。
- v22.4の早すぎる強制Sleep処理を廃止し、Matter.js本来のSleep判定に戻しました。
- 着地直後の線形速度・角速度だけを中程度に減衰し、姿勢が安定する前に固定される問題を改善。
- 多重バウンドと着地直後の急回転を抑えつつ、自然な回転・姿勢変化を残す調整に変更。
- 通常モードの地面をベース幅だけに戻し、ベース外へ完全に落下したピースが正しくゲームオーバーになるよう修正。
- エンドレスモードではベース左右に見えない壁を設置し、従来どおり横方向への落下を防止。
- 物理形状生成用のpiece.jsは変更していません。
