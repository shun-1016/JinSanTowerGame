# JinSan Tower Game

## v23.4
v23.4はv23.3をベースに、**物理パラメータを変更せず**、計測対象を8ピース単位で選択できるようにしたバージョンです。通常ゲームの物理挙動・ピース形状生成は変更していません。

### v23.1 デバッグ計測
`?debug=on` でゲームモード選択画面に、計測対象を選択するボタンが表示されます。

- 画像フォルダ内の連番ピースを検出し、8個ずつ（01〜08、09〜16…）に分割して表示
- 最後のグループは残りのピース数だけ表示
- 全ピースを同じ初期位置・初期角度・初速0で計測
- 落下開始から接地を検出
- 接地後60フレームまで継続記録
- 位置、速度、角速度、角度、Sleep状態、接地状態をフレーム単位で記録
- 質量、慣性、重心ズレ、従来の底面幅、縦横比、物理パーツ数、三角形数、領域数、輪郭頂点数も記録
- 最下端から1/2/4/8px以内の物理頂点幅を記録
- 実際の地面接触点の幅、接触点数、接触パーツ数、接触中心のズレを記録
- 計測完了後、CSVを自動出力し、画面から再保存も可能

### CSV
ファイル名は `JinSanTowerGame_v23.4_physics_log_01-08_YYYYMMDDHHMMSS.csv` のように、計測範囲を含めて出力されます。
CSVはUTF-8 BOM付きで、Excel等で開いた際に日本語が文字化けしにくい形式です。

### 通常ゲーム
v23.1では通常ゲームの物理パラメータ、ピース形状生成、ゲームルールを変更していません。
