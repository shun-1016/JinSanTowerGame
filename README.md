# 仁さんタワー

スマートフォン向けのローカル保存型・積み上げゲームです。GitHub Pagesで公開し、ブラウザ／ホーム画面追加（PWA）から利用します。

## v22.0

今回のv22.0では、物理形状の輪郭解析を改善したv21.8.5系の修正を正式版として整理し、HTML上のバージョン表示を `v22.0` に更新しました。

### 主な内容

- 画像の透明部分を考慮した輪郭解析
- 内部の透明な穴（空洞）を検出し、物理形状への反映を改善
- ピクセル単位の細かなギザギザを輪郭簡略化で抑制
- `.png` と `.PNG` の両方を読み込めるフォールバックを維持
- 物理エンジンの基本設定はv20.5由来の安定設定を維持
- ピースは01〜37の37種類
- 通常モードでは37種類をシャッフルして使用
- デバッグ時は `piece=1`〜`piece=37` で対象ピースを指定可能
- デバッグモードでは輪郭・三角形化・物理ポリゴン等を表示

## ファイル構成

```text
index.html
style.css
manifest.json
README.md
assets/
  01.png ... 37.PNG
js/
  physics.js
  piece.js
  renderer.js
  input.js
  game.js
  main.js
```

### JavaScriptの役割

- `physics.js`：Matter.jsの物理エンジン、衝突形状、物理演算
- `piece.js`：画像読み込み、透明部分からの輪郭解析、物理形状生成への入力
- `renderer.js`：Canvas描画、デバッグ表示、演出
- `input.js`：タッチ操作・ボタン操作
- `game.js`：ゲーム状態、モード、スコア、ピース選出、ゲーム進行
- `main.js`：起動処理とゲームループ

この分割構成は現状のまま維持しています。今回のv22.0でも、役割が異なるJavaScriptを統合する変更は行っていません。

## デバッグモード

URL末尾に以下を付けます。

```text
?debug=on
```

特定ピースを固定する場合：

```text
?debug=on&piece=24
```

`piece=1`〜`piece=37`を指定できます。

デバッグ表示では、輪郭頂点数、簡略化後の頂点数、面積、自己交差、三角形化結果、物理凸ポリゴン数、物理頂点数、検出した穴の数、Fallback状態などを確認できます。

## 通常モード

- 土台の外へ完全に落下するとゲームオーバー
- スコアはローカルストレージに保存
- 歴代ベスト3を表示

## エンドレスモード

- 左右に不可視の壁を設置
- ピースが左右から落下しない
- スコアは記録対象外

## 更新方法

今回のv22.0 ZIPに含まれるファイルを、リポジトリの同じパスへ上書きしてください。

```text
index.html       → リポジトリ直下
js/piece.js      → js/
js/renderer.js   → js/
js/game.js       → js/
README.md        → リポジトリ直下
```

`physics.js`、`input.js`、`main.js`、`style.css`、`manifest.json`、`assets/` は今回のZIPには含めていません。既存ファイルをそのまま使用してください。
