# JinSan Tower Game v18.1

v18.1をベースに、PNGのアルファマスクからピース形状を起動時に自動解析し、Matter.jsのcompound bodyとして物理判定に反映する版です。

## v18.1の変更
- `assets/01.png`～`21.png`を読み込み時に自動解析。
- 各画像をゲーム内表示サイズへ縮小したうえで、アルファ値から可視領域を抽出。
- 可視領域を横方向の帯状ランに分解し、Matter.jsで扱える凸四角形の集合へ変換。
- 複数の凸形状を1つのcompound bodyとして扱い、透明部分を基本的に当たり判定から除外。
- 21枚分の条件分岐・個別設定ファイルは使用しない。
- 解析結果は画像単位でキャッシュし、同じ画像を再解析しない。
- 物理パーツ数には上限を設け、スマートフォンでの負荷を抑える。
- Matter.js 0.20.0を使用。

## v18.1から維持するもの
- ソロプレイ
- カメラ制御
- スタンバイピースの初期位置
- タップだけではピースを移動しない処理
- 横方向のみのフリック移動
- 500msの次ピース生成待機
- 回転ボタン
- スマートフォン向けUI
