# JinSan Tower Game

## v23.1
v23.1はv22.6をベースに、**物理パラメータを変更せず**、全37ピースの物理挙動を同一条件で自動計測するデバッグ機能を追加したバージョンです。通常ゲームの挙動・物理チューニングは変更していません。

### v23.1 デバッグ計測
`?debug=on` でゲームモード選択画面に「全37ピース自動計測」が表示されます。

- 01〜37を順番に単独落下
- 全ピースを同じ初期位置・初期角度・初速0で計測
- 落下開始から接地を検出
- 接地後60フレームまで継続記録
- 位置、速度、角速度、角度、Sleep状態、接地状態をフレーム単位で記録
- 質量、慣性、重心ズレ、底面幅、縦横比、物理パーツ数、三角形数、領域数、輪郭頂点数も記録
- 計測完了後、CSVを自動出力し、画面から再保存も可能

### CSV
ファイル名は `JinSanTowerGame_v23.1_physics_log_YYYYMMDDHHMMSS.csv` です。
CSVはUTF-8 BOM付きで、Excel等で開いた際に日本語が文字化けしにくい形式です。

### 通常ゲーム
v23.1では通常ゲームの物理パラメータ、ピース形状生成、ゲームルールを変更していません。


## v23.1 修正内容
- v23.0で発生していたデバッグモード起動時のJavaScript初期化順序エラーを修正。
- 通常モード、エンドレスモード、自動計測が起動できる状態に修正。
- 物理パラメータ、ピース形状生成、計測内容は変更していません。
