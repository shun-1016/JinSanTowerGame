# 仁さんタワー

スマートフォン向けのローカル物理積み上げゲームです。
画像素材をMatter.jsの物理形状として扱い、ピースを左右に移動・回転させながら積み上げます。

## 公開ページ

GitHub Pages:

https://shun-1016.github.io/JinSanTowerGame/

## ゲーム概要

### 通常モード

土台の上にピースを積み上げます。
ピースが土台の外側へ完全に落下するとゲームオーバーになります。

通常モードのスコアは端末のlocalStorageに保存され、歴代ベスト3を表示します。
サーバーやデータベースは使用していません。

### エンドレスモード

左右に見えない壁があり、ピースが画面外へ落下しないモードです。
どこまでも積み上げられます。

エンドレスモードのスコアはランキングには保存されません。

## 操作

- **左回転**：落下前のピースを左回転
- **落とす**：現在のピースを落下させる
- **右回転**：落下前のピースを右回転
- **終了**：プレイ中のゲームをその時点で終了して結果を表示

スマートフォンではタッチ操作に対応しています。

## 主な機能

- Matter.js 0.20.0による2D物理演算
- 01.png〜36.pngの画像ピース
- 通常モードではピースをランダムに選出（36種類をシャッフルして順次使用）
- 画像のアルファ輪郭を利用した物理形状
- 通常モード / エンドレスモード
- 次のピース表示
- スコア・高さ表示
- 通常モードの歴代ベスト3保存
- ゲーム終了時の結果画面
- 落下・回転時の効果音
- 対応環境でのバイブレーション
- 朝 / 昼 / 夜の背景をランダム表示
- タワーの高さに応じたカメラ追従・背景暗転
- iPhoneホーム画面への追加に対応

## ホーム画面アイコン / PWA

ホーム画面追加用アイコンは `assets/icon.png` を使用しています。
`index.html` に `apple-touch-icon` とWeb App Manifestを設定しています。

`manifest.json` ではアプリ名を「仁さんタワー」、表示モードを `standalone` に設定しています。

### iPhoneでホーム画面に追加する場合

1. Safariで公開ページを開く
2. 共有メニューを開く
3. 「ホーム画面に追加」を選択
4. 追加

ホーム画面では設定した「仁さんタワー」のアイコンが使用されます。

## デバッグモード

通常アクセスではデバッグ表示を行いません。

### デバッグモード

```text
https://shun-1016.github.io/JinSanTowerGame/?debug=on
```

01.png〜36.pngを順番に固定して使用し、物理形状のデバッグ情報を表示します。通常モードとは異なり、再現性の確認をしやすくするための動作です。

### 特定画像を固定してデバッグ

`debug=on` と `piece=番号` を組み合わせます。

例：12.pngを固定

```text
https://shun-1016.github.io/JinSanTowerGame/?debug=on&piece=12
```

`piece` は01〜36を指定できます。

## デバッグ表示

- 青線：画像のアルファ輪郭
- 赤線：Matter.jsの実際の物理形状
- 緑点：Matter.jsの頂点
- 黄点：Matter.jsの各パーツ位置
- 紫点：Compound BodyのCOM
- 白十字：画像中心
- シアン枠：期待される画像中心

## 物理形状について

各ピースは画像のアルファ情報から輪郭を抽出し、Matter.jsで扱える凸ポリゴンのCompound Bodyへ変換しています。
画像と物理形状の座標を同期させ、見た目と当たり判定の外形を一致させる構成です。
