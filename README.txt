ベビータワーバトル v10 - 物理エンジン改修

変更対象:
- game.js のみ

今回の主な変更:
- 01.png～21.png の透明PNGを使用するよう固定
- 1枚の画像を1個の凸包として扱う方式を廃止
- 透明アルファマスクから複数の小さな凸矩形へ分解して衝突判定
- そのため、画像の凹み・脚の間・腕の間などをある程度空間として扱える
- 接触した矩形同士の接触点を支点として重力トルクを計算
- 地面でも実際の最下端を支点候補として回転
- 落下前に設定した回転角はそのまま維持し、接触後に物理的に回転
- 画面端の制限、カメラ追従、既存のUI/2人交互プレイは維持

アップロード方法:
1. GitHubリポジトリの game.js を開く
2. 編集または Upload files で、この game.js に置き換える
3. Commit changes
4. GitHub Pages の反映を待つ

注意:
- assets/01.png～21.png は今回の更新では変更不要です。
- 旧JPEGを参照する処理も game.js から削除しています。
